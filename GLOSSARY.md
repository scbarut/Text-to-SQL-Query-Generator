# Text-to-SQL Query Generator

A secure, analytics-capable tool that converts natural language questions into SQL queries.

## Language

**Query**:
The question asked by the user in natural language. The system converts it into SQL.
_Avoid_: Prompt, request, input

**Generated SQL**:
The SQL SELECT (or WITH...SELECT) statement generated by the LLM from a Query.
_Avoid_: Output, result query, response

**Schema Discovery**:
Automatic detection of all tables, columns, and relationships in the connected database from `sqlite_master`. Runs when the application starts or when `/refresh-schema` is called.
_Avoid_: Schema introspection, metadata scan

**Analysis**:
The process of recommending the appropriate chart type and configuration for query results — either via heuristic rules or via LLM.
_Avoid_: Visualization (visualization is the rendered output — not the process)

**Insight**:
A natural language sentence returned alongside a chart, summarizing the key finding or trend.
_Avoid_: Summary, description, comment

**Security Layer**:
The multi-layered validation pipeline applied to user input (sanitization), LLM output (SQL verification), and request rate (throttling).
_Avoid_: Firewall, filter, guard
